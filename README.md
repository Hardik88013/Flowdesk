# Flowdesk

Visual workflow automation platform for modern teams to design, automate, and monitor business processes.

## Live Demo

[https://flowdesk-plum-xi.vercel.app/](https://flowdesk-plum-xi.vercel.app/)

## Tech Stack

- Next.js (App Router, Turbopack)
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Features

- Responsive premium SaaS homepage
- Interactive workflow demonstration
- Workflow execution animation
- Node selection interaction
- Responsive navigation
- Easter egg

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Hardik88013/Flowdesk.git
   cd Flowdesk
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

5. Create an optimized production build:
   ```bash
   npm run build
   ```
